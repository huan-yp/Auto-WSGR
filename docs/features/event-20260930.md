# 20260930 最强之舟活动

本次在现有 BaseEventPage / NormalFightRunner 上增加活动资源与布局，保留旧活动配置。

## 使用

内置示例 `autowsgr/data/plan/event/20260930-E1.yaml` 可由
`run_event_fight_from_yaml(ctx, '20260930-E1', times=1)` 调用。
实际运行前配置模拟器和舰队。计划必须指定 `event: "20260930"`，
`chapter: E` 或 `H`，`map: 1` 至 `6`；本期不使用上期的 `1a` / `1b` 入口。
答题提示自动取消，不答题。首次进入、选图后及回港退出均检查该提示，最多取消三次。
预约弹窗继续使用已有主页面处理逻辑，新旧预约图片完全相同。

## 来源与地图映射

- [YaoerWu/Auto-WSGR classic 的 0930 提交](https://github.com/YaoerWu/Auto-WSGR/commit/b9ea3bc97eb104125a7bd7e95e8ad3080ae9b52b)
  提供六个节点入口坐标、活动入口/标题/出击/答题模板。模板原始分辨率为 960×540。
- 用户提供的 `maps.7z` 中 Backend 地图保留归一化坐标和 next 连线。
- Ex-1～Ex-6 导入为 E-1～E-6，Ex-7～Ex-12 导入为 H-1～H-6。
  **此难度映射仍待实机确认**；参考仓库的 H 计划与文件命名不匹配，不照搬其加载器。
- 仅导入本次活动的十二张地图，不覆盖压缩包中的其他常规地图。

## 防战

新增 Python `ShipType.AABG = '防战'`，共享 OCR 提取器与舰种白名单自动支持该文字，
船卡 metadata 增加 `aabg` 映射。此命名用于区别现有 `BG = '导战'`，不修改旧配置含义。
`autowsgr_native==0.3.0` 没有对应枚举，因此 native 敌舰识别和舰队规则 API 暂不支持此代码；
本次不伪造 native 类型或将防战混为导战。

防战解装筛选坐标没有实机样本：显式指定防战解装时，在点击前报错；
自动保留舰种解装额外保留防战并记录警告。未指定分类的全量解装模式沿用原逻辑。
